# epoch_markers

CBOR-focused encoders/decoders for Epoch Marker structures
as defined in [draft-ietf-rats-epoch-markers-03](https://datatracker.ietf.org/doc/html/draft-ietf-rats-epoch-markers-03).

## Minimum Supported Rust Version (MSRV)

This crate requires **Rust 1.85.0** or later.
