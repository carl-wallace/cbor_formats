# ar4si

CBOR-focused encoders/decoders for Attestation Results for Secure Interactions (AR4SI) structures
as defined in [draft-ietf-rats-ar4si-09](https://datatracker.ietf.org/doc/html/draft-ietf-rats-ar4si-09).

## Minimum Supported Rust Version (MSRV)

This crate requires **Rust 1.85.0** or later.
